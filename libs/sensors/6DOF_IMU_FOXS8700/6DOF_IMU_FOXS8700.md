![](https://cdn1-shop.mikroe.com/img/product/6dof-imu-3-click/6dof-imu-3-click-thickbox_default-1.jpg)This module is based on the **NXP** ***FOXS8700*** component that is a 3-axis accelerometer and magnetometer, in I2C.This directory contains :- *6DOF\_IMU\_FOXS8700.h* / *6DOF\_IMU\_FOXS8700.cpp* files : library files to include in your MBED OS project- *main_6DOF\_IMU\_FOXS8700.cpp* file : an example of using this Library- *6DOF\_IMU\_FOXS8700.bin* file : a precompiled file for *STMicroelectronics* Nucleo L476RG board (pins : SDA:D14 / SCL:D15)- *images* directory : images used for this tutorial## RessourcesTo obtain more informations about the Color14Click module from MikroE, you can check the [MikroE webpage](https://www.mikroe.com/color-14-click)For beginners who your **MBED Studio** or **Keil Studio** project.Then you have to include the header file (*6DOF\_IMU\_FOXS8700.h*) into your main code with the command :```c#include "6DOF\_IMU\_FOXS8700.h"```## How To Use### FOXS8700 ###This module uses an I2C interface (as a slave module) and an interrupt output to communicate with a microcontroller.###
